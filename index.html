      评分原理（透明可复核）

      1. 标准音标来自 Free Dictionary API 的 IPA；你的录音由本地 Whisper tiny.en 转写为文本，再查该识别词的 IPA。
      2. 音素对齐：把两串 IPA 按最长匹配切成音素，用 Levenshtein 对齐，算出替换 / 漏读 / 多读。
      3. 分数 = 100 × (1 − 编辑距离 / max(标准音素数, 你的音素数))，整词识别一致时加分并封顶 100。
      4. 不依赖 Google：不用 Web Speech API（Chrome 里走 Google）、不用 Google TTS / ML Kit / Firebase，package.json 零 Google 包。

      局限：Whisper 对口音、噪音敏感；个别单词无真人音频时会禁用播放按钮，但仍可录音评分。极慢速 0.40× 在个别浏览器上音质略有损失，属浏览器变速算法限制。
